# 豆姐锐评室

一套 Windows 本地双窗口直播软件。红围巾主播豆姐在 9:16 的深夜电台演播室里回弹幕、评投稿、接礼物。导播单独选题、排练和控制播出。只有舞台窗口播放声音。

## 开播

1. 完整解压项目，双击 `start-windows.cmd` 打开导播台和直播舞台。当前目录结构会使用风环岛项目自带的 Python 和 Electron。Electron 缺失或在窗口就绪前退出时，启动器会自动用 Windows WebView2 打开同样的两个窗口。升级前若旧版还开着，请先在旧版启动窗口按 Ctrl+C 退出。
2. 在导播台「设置」输入 DeepSeek API Key，点「保存设置」。默认模型为 `deepseek-flash`。在 Windows 上，通过导播台输入的密钥使用当前用户的 DPAPI 加密保存。也可以在启动前设置 `DEEPSEEK_API_KEY` 和可选的 `DEEPSEEK_MODEL`。
3. 在「设置 → 语音与采集」查看预热状态、选择播报语速。默认 1.18 倍，所选速度从新合成的台词开始生效。若舞台提示「开启声音」，在舞台点一次。
4. 首次启动默认自动接话。想自己挑题时，在「现场」关闭自动接话，从事件列表选中一条弹幕。投稿和手动台词在「插话」里输入。下次启动会沿用上次的接话设置。
5. 导播台和舞台的外框均固定为 450×800 逻辑像素。屏幕工作区较小时，两者按相同的 9:16 比例缩小。拖动导播台标题栏或按住舞台画面即可移位。「显示舞台」可找回已有窗口。关闭导播台会一并退出舞台和本地服务。
6. 在抖音直播伴侣或 OBS 中采集标题为「豆姐 · 直播舞台」的**应用窗口**，加上该窗口的应用音频。直播画布可设为 1080×1920。

## 排练一段完整互动

豆姐头顶的气泡把一问一答放在一起。上方用小字引用观众昵称和原评论，评论过长时显示开头。下方显示豆姐正在说的台词。长回复随语音翻页，引用的评论留在原位。[查看带礼物墙的 450×800 舞台排练画面](docs/stage-bubble.png)

| 在导播台的操作 | 舞台表现 |
| --- | --- |
| 在「排练」用昵称“小林”发弹幕“老板说，公司就是我第二个家。” | 气泡上方显示小林的弹幕，下方跟着豆姐的声音显示回应。口型、眼神和手势跟随台词。 |
| 在「排练」发“嘿嘿”或“。。。。” | 豆姐就着这条弹幕回一小句，一次说完。 |
| 在「排练」选择「进场」，昵称填“小林” | 开启自动接话时，豆姐只说“欢迎小林”。欢迎词由本地生成。 |
| 在她说话时到「排练」模拟观众送玫瑰，或点「模拟三连击」 | 玫瑰特效立即亮起，身后的礼物墙显示昵称、礼物和数量。豆姐说完手上这条就优先点名道谢，再拿礼物接梗。同一串连击在墙上更新数量。 |
| 从「排练」以同一昵称发弹幕“公司就是我第二个家”，听完后再发“那我真去问？” | 已播对话可以带入豆姐的下一次回答。真实采集有稳定账号 ID 时优先用该 ID 区分观众。 |
| 使用「跳过本条」或「急停」 | 跳过结束当前节目并继续排队。急停结束当前节目、清空待播并关闭自动接话；解除后可手动恢复。 |

专属礼物包括小心心、玫瑰、大啤酒、棒棒糖、加油鸭、荧光棒、礼花筒、浪漫花火和跑车。每种都有自己的镜头内特效、台词和动作组合。豆姐能拿起玫瑰、啤酒罐、棒棒糖或荧光棒，加油鸭会跳上麦克风旁的桌面。其他礼物统一亮起一个带星光的开盖礼盒，照常按实际昵称、礼物名和份数上墙、道谢。

## 在导播台调人设

顶部「人设」页可以查看豆姐正在用的提示词。默认豆姐脾气冲、爱摆谱，也爱显摆自己挑的贵东西。观众来挑衅，她一句话顶回去。观众吐槽同事抢功，她就拿署名开涮。真有人问该怎么办，她嘴上刻薄，话里照样给个能用的办法。

1. 修改提示词后，在「后台试词」输入一条弹幕，例如“叫声老公听听”，或选择礼物和数量，点「生成试词」。结果仅在导播台显示。笑声、表情和一串标点直接试听本地短句。需要模型写词时，使用已配置的 DeepSeek 和当前人设草稿。
2. 看结果旁的来源。弹幕和投稿可由 DeepSeek 按人设生成。直播里礼物先用内置台词报出实际礼物和数量，首句播到一半也能接上模型刚写好的收尾。首句太短或模型回得太晚时，会接着播已准备好的内置包袱。
3. 满意后点「保存人设」，之后的新回复会使用这份人设，重启也会恢复。「载入默认人设」先把预设放回编辑框，再点保存即可上线。

### 让观众从桌上的东西接话

从观众视角看，桌面左侧是 iPhone Duo。折叠手机下半部平放，上半部像迷你笔记本一样掀起，银白后盖和苹果标志朝向观众。桌子右后方有波形监视器。可以在「排练」里问“左边那个是小电脑吗？”或“你脖子上那条是什么颜色？”，看豆姐怎么接梗。

豆姐身后上方的礼物墙从左到右列出当前房间最近三笔赠礼，最新一笔在左。昵称、礼物名和份数来自采集记录，同一串玫瑰从 ×1 到 ×3 再到 ×5 会更新为 ×5。换房间显示各自的礼物墙，重开舞台只恢复记录。礼物到达时才亮对应特效。

在「人设」展开「查看舞台陈设和豆姐的穿搭」可以核对镜头位置和物件特征。桌面左右以观众看到的画面为准。观众指着摆件评论、问穿搭或接着追问时，豆姐才按清单接话。观众换个话题说加班，她也跟着聊加班。

## 声音和接话

观众的文字作为引用显示，豆姐只念自己的回答。笑声、表情和一串标点由本地接一句。简短提问也用一句话答到点上。观众把情况说得详细、问了几件事或明确请她展开时，她才多讲几句。导播输入的手动台词按原文播报。

所有播报共用风环岛的 GPT-SoVITS 音色。当前目录结构可直接使用相邻项目中的 `..\windring-island\voice`。程序复用其中的参考录音、参考文本、微调权重、推理环境和 Python。移动到其他电脑时，复制完整的 `voice` 目录到本项目根目录，或把 `DOUJIE_VOICE_DIR` 指向它。运行环境与风环岛相同，需能运行其 Windows NVIDIA/CUDA 推理引擎。

开启自动接话后，新互动先触发舞台提示。豆姐会先看向刚选中的弹幕，语音引擎送出第一段可播放的声音后立即开口，播放期间继续合成后面的声音。若此时收到礼物，会先出特效，再安排礼物回应。默认语速也可在启动前用 `DOUJIE_SPEECH_RATE` 设置，范围 0.8 至 1.6。

有礼物时自动播报优先感谢送礼观众。空档里弹幕和有昵称的进场都在等时，按约 7 次评论、3 次欢迎穿插。有一类暂时没有可播内容时，另一类直接用麦。导播点选和手动送播沿用导播优先级。

同一直播间 6 秒内收到 4 条弹幕，或待回弹幕积到 4 条，就进入刷屏模式。豆姐挑新评论接话，如果一个具体问题刚被笑声顶过去，她会优先接这个问题。导播台把让位的弹幕标为「刷屏略过」，导播仍可点「回复」。

平时连续点赞会合并回应。豆姐从本地短句中挑一句，避开同一直播间最近说过的点赞梗。采集器只提示有人点赞时，她不会报具体数量。弹幕刷屏时，待播的点赞和新收到的点赞都只留记录。连续 6 秒没有新弹幕后，豆姐恢复接新赞。

持续刷屏时，两次邀礼至少相隔 25 秒。有合适的问题就先答，再在同一段末尾接一句邀礼。如果屏上都是笑声、标点，或这条弹幕只够再问一句，豆姐可以直接对全场要一朵玫瑰，气泡里不会挂某位观众的名字。收礼、观众聊礼物或导播点名时会跳过额外邀礼。连续 6 秒没有新弹幕后恢复平时的接话节奏。

观众进场时，本地直接生成“欢迎＋昵称”，交给豆姐的音色播报。舞台在 15 秒内还没接手的欢迎会过期，进场记录仍可在导播台查看。采集器只给出无名的多人汇总时，仅记录人数。

没有配置 DeepSeek 时可以用内置台词排练。接口超时或回复格式异常时，本条回落到本地台词。没有可用语音时舞台继续表演并显示字幕。

## 重启后保留什么

新收到的互动、导播投稿、手动台词、已播内容、人设以及接话和语音设置都会保存到本机。导播台可翻看更早的记录。重启后，此前排队或中断的台词留有记录，开播从新互动开始。旧版已经随进程关闭而丢失的数据无法补录。

默认端口的数据文件是 `%LOCALAPPDATA%\DoujieStudio\data\studio-8080.sqlite3`。不同端口各自保存，也可在启动前用 `DOUJIE_DATA_DIR` 指定数据目录。要备份记录，先关闭导播台，再复制这个目录。已保存的密钥只在原 Windows 用户环境下解密。

## 本机地址

| 用途 | 默认地址 |
| --- | --- |
| 导播台 | `http://127.0.0.1:8080/` |
| 竖屏舞台 | `http://127.0.0.1:8080/stage.html` |
| 采集器推送 | `POST http://127.0.0.1:8080/live-events` |

原有直播采集器继续通过 `--push-url` 推送，无需改动直播平台账号。接入字段和示例见 [直播事件协议](docs/live-events.md)。程序只监听本机回环地址。若端口已占用，可用 `start-windows.cmd --port 8090` 启动，同时修改采集器的推送地址。

## 开发与验证

应用使用 Python 标准库、SSE 和项目内的 Three.js。页面、角色和演播室都从本机加载。Windows x64 备用窗口使用系统的 Microsoft Edge WebView2 运行时。需要单独安装 Electron 时，可在 Node.js 22.12 或更新版本下执行 `npm ci`，或用 `DOUJIE_ELECTRON` 指定本机已有的 `electron.exe`。服务端支持 Python 3.10 及以上版本。

双击启动失败时，命令窗口会停留在错误信息处。按 Win+R 输入 `%LOCALAPPDATA%\DoujieStudio\startup.log` 可查看最近一次启动用了哪个桌面运行时、窗口是否就绪及退出码。若这个目录不可写，日志保存在项目根目录的 `doujie-startup.log`。已经启动时再次双击会调出原导播台。

运行 `python launch.py --no-browser` 可单独启动本地服务，手动输入页面地址进行浏览器预览。运行 `python -m unittest discover -v` 可执行后端测试。如仅安装了风环岛的 Python，在 PowerShell 中可运行：

```powershell
& ..\windring-island\voice\runtime\python\python.exe -m unittest discover -v
```
